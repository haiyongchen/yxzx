## OA 邮件分析技能开发 ✅ 已沉淀

### 技能位置
- `skills/oa-mail-analyzer/SKILL.md` - 技能文档 ✅
- `skills/oa-mail-analyzer/scripts/analyzer_v5.py` - 主脚本

### 功能
1. 自动登录 OA 系统（Cookie 复用，无需每次扫码）
2. 获取指定天数内的邮件列表（默认 7 天）
3. 逐封阅读邮件正文内容
4. 智能分类：电子商城、招投标、系统通知、工作汇报、培训学习
5. 优先级标注：⭐⭐⭐（紧急）、⭐⭐（重要）、⭐（一般）
6. 生成飞书表格和文档

### 使用方法
```bash
python D:\openclaw-workspace\skills\oa-mail-analyzer\scripts\analyzer_v5.py
```

### 配置参数
- `DAYS_RANGE = 7` - 分析天数
- `MAX_MAILS_TO_READ = 15` - 最多阅读邮件数

### 输出
- 飞书表格：https://www.feishu.cn/sheets/SO2Xs2vlkh4XKNt0VfOclqWYn6g

- 本地 JSON：`D:\openclaw-workspace\oa_mails_full.json`

### 技术要点
1. OA 系统使用 iframe 架构，邮件详情 URL 不会变化
2. 所有邮件统一入口：`https://oa.epoint.com.cn/OA9/oa9/mail/mailframe`
3. 飞书 API 需要 App ID 和 App Secret 获取 Token
4. 飞书表格使用 Sheets API v2
