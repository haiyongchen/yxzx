## ⚠️ 发现的问题与限制

### 1. 验证码处理能力
- **问题**: 无法自动处理拼图验证码
- **影响**: 访问某些网站需要用户协助
- **解决**: 使用 Playwright 打开浏览器，用户手动完成验证

### 2. clawhub API 速率限制
- **问题**: 未认证用户有速率限制
- **影响**: 频繁搜索会触发限制
- **解决**: 使用 `npx clawhub` 时添加 `-y -g` 参数

### 3. summarize 技能平台限制
- **问题**: 依赖的 CLI 工具仅支持 macOS
- **影响**: Windows 上无法使用
- **解决**: 寻找替代方案或使用在线服务

### 4. 配置变更流程
- **教训**: 修改配置后不应自动重启网关
- **改进**: 先询问用户确认
