# 统一存储规格说明

## NAS存储
- **初始容量(3年)**: 1TB
- **IOPS**: 不低于2000
- **网络**: 千兆
- **共享方式**: NFS
- **端口**: 2049、30001~30004、111
- **性能基准**: 以1000份100MB加密文件做解密性能压测
  - 5000IOPS + 千兆带宽: 60分钟
  - 5000IOPS + 万兆带宽: 30分钟
  - 20000IOPS + 万兆带宽: 15分钟

## 存储目录说明
- **AttachStorage**: 应用附件存储主目录
- **EpointMisTempFile**: 临时文件目录
- **SliceUploadPath**: 分片上传目录（会员端专用）
- **/opt/epoint/filedownload**: 数据交换下载目录
- **/opt/epoint/filestorage**: 数据交换存储目录
- **/opt/website**: 网站文件目录
- **/opt/nasshare**: NAS共享目录
- **/opt/filemanage**: 文件管理目录

## 注意事项
1. 存储目录需区分，不同应用挂载不同目录
2. 应用挂载需填写：容器路径、文件服务器目录路径
3. 文件备份服务器单独规划，不与业务存储共用
4. IOPS 不低于500（应用服务器最低值），中间件不低于1000
