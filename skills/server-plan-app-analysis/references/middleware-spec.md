# 基础中间件规格说明

## 概述

基础中间件是多个产品共享的底层服务，包括 Redis、Nginx、RabbitMQ。部署原则：
- 按产品应用分离部署
- 面客端应用（网站、竞价、不见面开标大厅）稳定性要求高或容易被攻击的建议单独部署
- 每10个接入应用需加倍资源

## 规格清单

### Redis缓存服务
- **配置**: 4C / 8G / 200G / 千兆
- **端口**: 6379
- **IOPS**: 不低于1000
- **风险**: 每10个接入应用端应用需加倍资源
- **建议**: 网站、竞价、不见面开标大厅这类面客端应用稳定性要求高或容易被攻击的单独部署

### Nginx统一对外访问服务
- **配置**: 4C / 4G / 200G / 千兆
- **端口**: 80、443
- **IOPS**: 不低于1000
- **风险**: 每20个接入应用端应用需加倍资源

### RabbitMQ消息队列服务
- **配置**: 4C / 8G / 200G / 千兆
- **端口**: 5671、5672、15672、1883、1882
- **IOPS**: 不低于1000
- **风险**: 每10个接入应用端应用需加倍资源

## 合并规则

1. 多个产品共用时，Redis 按 DBIndex 分配隔离
2. Nginx 按产品分组配置反向代理
3. RabbitMQ 按产品配置不同 vhost
4. 如某产品明确要求独立部署（如面客端），则单独规划
