扫码后 Token 文件未生成，说明登录流程没有完成。

## 可能原因
1. 扫码后没有在 OA App 上点击"确认登录"
2. 二维码已过期
3. 网络问题导致 Token 保存失败
4. 扫码的是终端二维码而不是图片查看器

## 下一步方案

### 方案 A：重新扫码（推荐）
1. 运行 `python oalogin_windows.py`
2. 等待 Windows 图片查看器打开
3. 用 OA App 扫描**图片查看器中的二维码**
4. 在 OA App 上点击"确认登录"
5. 等待脚本自动保存 Token

### 方案 B：使用浏览器 Cookie
如果浏览器已保存 OA 登录状态，可以直接使用 Cookie 提交日志，无需扫码。

### 方案 C：手动填写
使用 `使用说明.md` 中的命令手动提交日志。
