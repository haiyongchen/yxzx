| **Content-Type** | `application/x-www-form-urlencoded` |
| **描述** | 无 |

#### 请求参数

| 参数名 | 类型 | 必填 | 描述 |

## 提交知识库反馈

| 属性 | 内容 |
| :--- | :--- |
| **标识符** | `knowledge_addfeedback_v7` |
| **API 路径** | `http://oa.epoint.com.cn/oaextend/rest/dynamicapi/knowledge_addfeedback_v7` |
| **请求方法** | `POST` |
| **Content-Type** | `application/x-www-form-urlencoded` |
| **描述** | 无 |

#### 请求参数

| 参数名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `problemguid` | STRING | 是 | 当前反馈所属知识库 |
| `chkneednotify` | STRING | 是 | 开关开启为 `1`，关闭为 `0` |
| `txtNotifyUsersGuid` | STRING | 否 | 多人之间用英文分号 `;` 分隔 |
| `txtNotifyUsersName` | STRING | 否 | 多人之间用英文分号 `;` 分隔 |
| `TimeConsuming` | STRING | 否 | 页面允许输入小数 |
| `txtcontent` | STRING | 是 | 页面校验非空 |
| `peihefinishdate` | STRING | 否 | 格式 `yyyy-MM-dd` |

#### 响应参数内容

| 参数名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `根节点` | OBJECT | 否 |  |

**请求示例:**
```json
{"problemguid": "", "chkneednotify": "1", "txtNotifyUsersGuid": "", "txtNotifyUsersName": "", "TimeConsuming": "0", "txtcontent": "", "peihefinishdate": "当前日期"}
```

**响应示例:**
```json
{"status": {"code": "1", "text": ""}, "custom": {}}
```
