# OA 接口清单 - 通讯录

> 分类 GUID: `055198d6-6eef-47d2-a63c-ab357e6dde6f`

## 获取用户详情

| 属性 | 内容 |
| :--- | :--- |
| **标识符** | `address_getuserdetail_v7` |
| **API 路径** | `http://oa.epoint.com.cn/oaextend/rest/dynamicapi/address_getuserdetail_v7` |
| **请求方法** | `POST` |
| **Content-Type** | `application/x-www-form-urlencoded` |
| **描述** | 无 |

#### 请求参数

| 参数名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `userguid` | STRING | 是 | 用户 GUID |
| `ryidentification` | STRING | 否 | 人员标识类型，默认 1 |

#### 响应参数内容

| 参数名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `根节点` | OBJECT | 否 |  |

**请求示例:**
```json
{"userguid": "user-guid-1", "ryidentification": "1"}
```

**响应示例:**
```json
{"status": {"code": "1", "text": "请求成功"}, "custom": {"userguid": "user-guid-1", "displayname": "张三(部门)", "ouguid": "ou-guid-1"}}
```
