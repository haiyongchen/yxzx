## 🔧 使用流程

### 方法 1：手动扫码 + 自动提交（推荐）

#### 步骤 1：扫码登录
```bash
cd D:\openclaw-workspace\skills\oa-diary\oa
python scripts\oalogin.py
```

```bash
python scripts\oa_api.py rz_insert_rzdetail_v2 "{\"rzdate\":\"2026-04-20\",\"rzguid\":\"xxx\",\"missionguid\":\"xxx\",\"missionname\":\"日常运维\",\"gongzuosj\":\"8\",\"completepercent\":100,\"gongzuonr\":\"工作内容\",\"contenttype\":\"01\",\"gzdworktype\":\"0103\",\"projectname\":\"运营维护\",\"projectguid\":\"xxx\"}"
```

1. 打开 Chrome 浏览器
2. 访问：https://oa.epoint.com.cn:8080/OA9/oa9/mail/mailframe
3. 应该会自动登录（使用已保存的 Cookie）
4. 手动填写日志

## 🔍 常用 API 命令

### 查询今日日志
```bash
python scripts\oa_api.py rz_select_rzinfo_list_v1 "{\"fromdate\":\"2026-04-20\",\"todate\":\"2026-04-20\"}"
```

### 获取服务器时间
```bash
python scripts\oa_api.py rz_getnowtime_v1 "{}"
```

### 获取工作类型
```bash
python scripts\oa_api.py rz_select_gzdworktype_v1 "{\"parentareacode\":\"\"}"
```

### 获取任务列表
```bash
python scripts\oa_api.py rz_select_missioninfo_v1 "{\"fromtype\":\"1\",\"cxprojectname\":\"\",\"cxbegindate\":\"2026.04.01\",\"cxenddate\":\"2026.04.30\"}"
```

## ⚠️ 注意事项

1. **Token 有效期**：Token 有一定有效期，过期后需要重新扫码
2. **参数依赖**：提交日志需要 `rzguid`, `missionguid`, `projectguid` 等参数，需要先查询
3. **编码问题**：Windows 控制台使用 UTF-8 编码

## 💡 自动化建议

如果要实现完全自动化，需要：
1. 定期更新 Token（设置定时任务，每天扫码或通过其他方式刷新）
2. 预先配置默认的任务和项目 GUID
3. 使用 Playwright + Cookie 实现自动登录
