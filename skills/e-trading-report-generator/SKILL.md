# e交易专区收益成本统计报告生成器

## 功能概述

本skill用于根据e交易专区数据自动生成收益成本统计报告Word文档。报告包含：
- 核心数据概览（六大指标统计表格）
- 风险等级分布说明
- 收益分析（25年收益分布、流失风险专区）
- 后续处理建议
- 关键任务表格

## 输入数据要求

Excel数据文件需包含以下列：
- 合同编号
- 专区码
- 专区名称
- 客户类型
- 所属
- 分公司
- 省份
- 地市
- 所属平台
- 确认接入时间（日期格式）
- 专区状态
- 25年收益情况（数值）
- 26年收益情况（数值）
- 总收益情况（数值）
- 实际人工成本（数值）

## 使用流程

### 1. 准备数据文件

确保数据文件为.xlsx格式，包含上述所有列。

### 2. 运行报告生成脚本

**Python版本（推荐，支持图表生成）：**
```bash
python <skill_path>/generate_report.py <data_file_path> [output_dir]
```

**Node.js版本（仅生成文档）：**
```bash
node <skill_path>/generate_report.js <data_file_path> [output_path]
```

参数说明：
- `data_file_path`: 必填，数据Excel文件路径
- `output_dir/output_path`: 可选，输出目录/路径，默认为数据文件同级目录

### 3. 查看生成的报告

生成的报告将包含完整的：
- 数据统计摘要（七大指标）
- 三张可视化图表（风险分布饼图、收益分布柱状图、TOP10流失风险）
- 风险等级分类说明
- 处理建议
- 关键任务清单

## 统计指标说明

报告会自动计算以下指标：

| 指标 | 条件 | 风险等级 |
|------|------|----------|
| 指标一 | 接入超过1年，总收益为0 | 红色-重点关注 |
| 指标二 | 接入超过1年，0<总收益<10w | 红色-重点关注 |
| 指标三 | 接入超过1年，0<总收益<5w | 红色-重点关注 |
| 指标四 | 接入超过3个月，小于1年，总收益为0 | 红色-重点关注 |
| 指标五 | 25年前接入，0<25年收益<5w | 橙色-需改进 |
| 指标六 | 26年产生收益 | 黄色-观察 |
| 指标七 | 25年有收益，26年无 | 灰色-流失风险 |
| 指标八 | 接入超半年，总收益为0 | 深红-紧急关注 |

## 技术实现

- 使用Node.js + docx库生成Word文档
- 使用Python + pandas/openpyxl读取Excel数据
- 支持自定义样式和格式

## 依赖

- Node.js
- docx npm包
- Python 3.x
- pandas
- openpyxl
