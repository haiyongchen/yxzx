# e交易专区收益成本统计报告生成器

## 简介

本工具用于根据e交易专区数据自动生成收益成本统计报告Word文档。报告包含完整的数据分析、风险等级划分、处理建议和关键任务清单。

## 功能特点

- 📊 自动分析Excel数据，计算七大关键指标
- 🎨 生成格式化的Word报告，包含表格和结构化内容
- 🏷️ 支持风险等级分类（红色/橙色/黄色/灰色）
- 📝 包含处理建议和关键任务清单
- 🖼️ 预留图表占位符，方便后续插入可视化图表

## 使用方法

### 命令行使用（Python版本 - 推荐）

```bash
python generate_report.py <数据文件路径> [输出目录]
```

**参数说明：**
- `数据文件路径`: 必填，e交易专区数据Excel文件(.xlsx)的完整路径
- `输出目录`: 可选，生成报告和图表的保存目录，默认为数据文件同级目录

**示例：**

```bash
# 基本用法
python generate_report.py "D:/data/中原华北区专区数据_成本更新.xlsx"

# 指定输出目录
python generate_report.py "D:/data/中原华北区专区数据_成本更新.xlsx" "D:/output"
```

### 命令行使用（Node.js版本 - 仅文档）

```bash
node generate_report.js <数据文件路径> [输出文件路径]
```

**示例：**

```bash
node generate_report.js "D:/data/中原华北区专区数据_成本更新.xlsx"
```

## 输出报告结构

生成的Word报告包含以下章节：

### 1. 概述
- 数据统计范围说明
- 风险分级体系介绍
- 主要发现摘要

### 2. 核心数据概览
- **1.1 七大指标统计表格（含新增指标八：接入超半年无收益）**
  - 指标一：接入超过1年，总收益为0（红色）
  - 指标二：接入超过1年，0<总收益<10w（红色）
  - 指标三：接入超过1年，0<总收益<5w（红色）
  - 指标四：接入超过3个月，小于1年，总收益为0（红色）
  - 指标五：25年前接入，0<25年收益<5w（橙色）
  - 指标六：26年产生收益（黄色）
  - 指标七：25年有收益，26年无（灰色）
  - 指标八：接入超半年，总收益为0（深红-紧急关注）

- **1.2 风险等级分布**
  - 红色-重点关注：处理对象和措施
  - 橙色-需改进：处理对象和措施
  - 黄色-观察：处理对象和措施
  - 灰色-流失风险：处理对象和措施

### 3. 收益分析
- 2.1 25年收益分布分析
- 2.2 流失风险专区TOP10

### 4. 后续处理建议
- 3.1 红色等级专区（立即处理）
- 3.2 灰色等级专区（紧急跟进）
- 3.3 橙色等级专区（持续优化）

### 5. 关键任务
- 包含序号、实施工作、负责人、计划完成节点、备注的完整任务表格

### 6. 附录
- 数据来源说明

## 统计指标说明

| 指标 | 计算条件 | 风险等级 | 业务含义 |
|------|----------|----------|----------|
| 指标一 | 确认接入时间 < 2025-04-08 且 总收益情况 = 0 | 红色 | 长期零收益专区 |
| 指标二 | 确认接入时间 < 2025-04-08 且 0 < 总收益情况 < 100000 | 红色 | 长期低收益专区 |
| 指标三 | 确认接入时间 < 2025-04-08 且 0 < 总收益情况 < 50000 | 红色 | 长期极低收益专区 |
| 指标四 | 确认接入时间 > 2025-04-08 且 <= 2026-01-08 且 总收益情况 = 0 | 红色 | 3个月-1年零收益专区 |
| 指标五 | 确认接入时间 < 2025-01-01 且 0 < 25年收益情况 < 50000 | 橙色 | 25年极低收益专区 |
| 指标六 | 26年收益情况 > 0 | 黄色 | 正常运营专区 |
| 指标七 | 25年收益情况 > 0 且 26年收益情况 = 0 | 灰色 | 客户流失风险专区 |
| 指标八 | 确认接入时间 < 当前日期-180天 且 总收益情况 = 0 | 深红 | 半年无收益专区 |

## 注意事项

1. **日期格式**：确保"确认接入时间"列为标准日期格式
2. **数值格式**：收益相关列应为数值类型，不包含千分位逗号
3. **图表占位符**：生成的报告包含图表占位符【图1】【图2】【图3】，需要手动插入实际图表
4. **编码问题**：如遇到中文乱码，请确保系统使用UTF-8编码
