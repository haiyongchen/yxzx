# OA 邮件分析技能

自动登录 OA 系统，获取指定时间范围内的邮件，阅读正文内容，智能分类并生成**飞书在线文档和表格**。

## 📋 功能特性

- ✅ **Cookie 自动复用** - 使用已保存的登录状态，无需每次扫码
- ✅ **可配置时间范围** - 支持分析最近 N 天的邮件（默认 7 天）
- ✅ **阅读邮件正文** - 自动点开每封邮件，提取完整内容
- ✅ **智能分类** - 自动将邮件分为 5 类（电子商城、招投标、系统通知、工作汇报、培训学习）
- ✅ **优先级标注** - 根据内容自动标注优先级（⭐⭐⭐/⭐⭐/⭐）
- ✅ **飞书集成** - 自动生成飞书在线文档和表格
- ✅ **详细报告** - 包含分类统计、优先级分布、邮件详情、待办事项

## 🚀 使用方法

### 基础使用（分析最近 7 天）

```bash
python D:\openclaw-workspace\skills\oa-mail-analyzer\scripts\analyzer_v5.py
```

### 自定义时间范围

编辑脚本配置参数：
```python

MAX_MAILS_TO_READ = 15  # 最多阅读邮件数
```

## 🔧 技术实现

### 核心流程

```
1. 启动浏览器（使用持久化 Cookie）
   ↓
2. 访问 OA 邮件系统
   ↓
3. 获取邮件列表（解析 iframe 内容）
   ↓
4. 逐封阅读邮件（点击→提取内容→返回）
   ↓
5. 智能分类（关键词匹配）
   ↓
6. 优先级标注（关键词匹配）
   ↓
7. 生成临时 Markdown 文件（飞书文档内容）
   ↓
8. 生成临时 JSON 文件（飞书表格数据）
   ↓
9. 保存本地备份（Markdown）
   ↓
10. 手动创建飞书文档和表格（使用临时文件）
```

### 依赖库

```bash
pip install playwright
playwright install chrome
```

### iframe 处理

OA 系统使用 iframe 架构，邮件详情在 iframe 内加载：
```python
frame = page.frame_locator('#mail-rightframe')
body_text = frame.locator('body').inner_text(timeout=5000)
```

## ⚠️ 注意事项

1. **Cookie 有效期**: 登录状态有一定有效期，过期后需要重新扫码
2. **网络要求**: 需要能访问 OA 系统和飞书
3. **浏览器**: 默认使用 Chrome，需安装 Playwright
4. **手动创建文档**: 当前版本生成临时文件，需手动创建飞书文档和表格
5. **超时处理**: 大量邮件可能需要较长时间，建议设置合适超时
