# 输出格式模板

## Excel 输出格式

### Sheet1: 服务器部署清单

列定义：

| 列名 | 说明 | 示例 |
|------|------|------|
| 序号 | 自增编号 | 1 |
| 方案模式 | 标配非集群/标配集群 | 标配非集群 |
| 支持操作系统 | 操作系统版本 | centos7.9最小化安装 |
| 资源类型 | 虚拟机/实体机/GPU | 虚拟机 |
| 所属环境 | 正式环境/测试环境 | 正式环境 |
| 服务器类型 | 应用服务器/中间件/数据库/存储 | 应用服务器 |
| 中间件 | 中间件类型 | Tomcat |
| 服务器用途 | 部署的应用列表 | 交易平台中心端、统一认证平台 |
| CPU | 核数 | 8 |
| 内存(G) | 内存大小 | 16 |
| 磁盘空间(G) | 磁盘大小 | 200 |
| 放行端口 | 端口列表 | 8080、8081、8082 |
| 方案描述 | 部署说明 | 标准部署方案 |

### Sheet2: 资源汇总

| 项目 | 数值 |
|------|------|
| vCPU合计 | - |
| 内存合计(G) | - |
| 磁盘合计(G) | - |
| 服务器总台数 | - |

### 格式规范
- 表头蓝色背景白字
- 数据行交替灰白底色
- 合计行加粗
- 冻结首行
