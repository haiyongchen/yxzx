# 资源测算公式与方法

## 动态测算（有性能基线时）

### 应用服务器测算

**业务系统（会员端）：**
- 公式：`ROUNDUP(最大在线用户数 / 2500, 0)` 台
- 并发比例：10%
- 3年增幅：30%
- 示例：10000在线用户 → 4台

**业务系统（中心端）：**
- 公式：`ROUNDUP(最大在线用户数 / 1000, 0)` 台
- 示例：100在线中心人员 → 1台

**评标系统：**
- 公式：`ROUNDUP(同时评标标段数 / 15, 0)` 台
- 集群性能下降：10%

**不见面开标大厅：**
- 公式：`ROUNDUP(最大在线用户数 / 3000, 0)` 台

### 数据库服务器测算

**业务数据库：**
- CPU：`ROUND(最大在线用户数 / 2000, 0) * 16`
- 配置基准：16C / 32G / 2T

**开评标数据库：**
- CPU：`ROUND(同时评标标段数 / 15, 0) * 16`
- 配置基准：16C / 32G / 1T

**开标大厅数据库：**
- CPU：`ROUND(最大在线用户数 / 3000, 0) * 16`

### 存储容量测算

**NAS存储月增长：**
- 公式：`ROUND(平均每日标段数 * 平均每标段单位数 * 3 / 1024 / 1024 * 22, 1)` TB

## 静态估算（无性能基线时）

### 按项目规模估算

| 项目规模 | 月标段数 | 在线用户 | 应用服务器 | 数据库 |
|---------|---------|---------|-----------|--------|
| 小型 | <50 | <1000 | 8C16G × 6~8台 | 8C16G × 1台 |
| 中型 | 50~200 | 1000~5000 | 8C16G × 10~15台 | 16C32G × 1~2台 |
| 大型 | 200~500 | 5000~20000 | 8C16G~16C32G × 15~25台 | 16C32G × 2~3台 |
| 超大型 | >500 | >20000 | 需性能测试 | 需性能测试 |

### 合并后资源计算

**同台叠加规则：**
- 2个应用同台：取最大CPU × 1.2，内存累加 × 0.9
- 3个应用同台：取最大CPU × 1.5，内存累加 × 0.8
- 4个及以上：建议拆分

**IOPS要求：**
- 应用服务器：≥ 500
- 中间件服务器：≥ 1000
- 数据库服务器：≥ 5000
- 文件服务器：≥ 2000

### 物理机换算

虚拟化比例：3:1（每3个vCPU对应1个物理核）

**物理机配置参考：**
- CPU：2×英特尔至强金牌5218(16核)
- 内存：8×32GB
- 硬盘：2×600GB SAS
- RAID卡：≥2GB缓存

**计算公式：**
- 物理CPU数量 = vCPU合计 / (单颗核心数 × 虚拟化比例)
- 物理机台数 = ROUNDUP(物理CPU数量 / 2, 0)（每台2颗CPU）
- 内存条数 = 内存合计 / (单根容量 × 每台服务器插槽数)
